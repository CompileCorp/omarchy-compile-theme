# Wallpaper

This theme uses a single wallpaper from Wallhaven.

## Installation

Download the wallpaper and place it in this directory as `wallpaper.png`:

**Wallpaper URL:** https://w.wallhaven.cc/full/8g/wallhaven-8g5qr2.png

### Manual Download

1. Visit: https://wallhaven.cc/w/8g5qr2
2. Download the wallpaper
3. Save it as `wallpaper.png` in this directory

### Using wget (if the site allows)

```bash
wget -O wallpaper.png "https://w.wallhaven.cc/full/8g/wallhaven-8g5qr2.png"
```

## Usage

The wallpaper is referenced in `hyprlock.conf` and can be used as your desktop background.
